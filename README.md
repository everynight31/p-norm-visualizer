# p 范数单位球面可视化

三维空间中 **p 范数单位球面**（`||x||_p = 1`）的交互式可视化。拖动滑条改变 p 值，实时观察球面形状的连续变形。

## 数学背景

p 范数定义为

```
||x||_p = (|x₁|^p + |x₂|^p + |x₃|^p)^(1/p)
```

单位球面是满足 `||x||_p = 1` 的所有点构成的集合。改变 p 值，球面形状随之变化：

| p 值 | 形状 | 对应距离 |
|---|---|---|
| p < 1 | 非凸的星形凹面体 | 非范数（不满足三角不等式） |
| p = 1 | 正八面体 | 曼哈顿距离 |
| p = 2 | 标准球面 | 欧几里得距离 |
| p → ∞ | 立方体表面 | 切比雪夫距离 |

## 功能

- 拖拽旋转三维视角
- 滚轮缩放
- 对数刻度滑条实时调整 p 值（0.5 ~ 20），左右手感一致
- 网格精度可调
- 颜色随 p 值渐变

## 使用

直接用浏览器打开 `index.html` 即可，零依赖、可离线使用。

## 实现说明

纯 HTML + Canvas 2D，无任何外部依赖：

1. 用球坐标参数化单位球面，得到方向向量；
2. 按 p 范数公式计算该方向的范数并归一化，得到 p 范数单位球面上的点；
3. 对经纬网格逐段做透视投影并绘制。

核心片段：

```js
// 方向向量
const x = Math.sin(v) * Math.cos(u);
const y = Math.sin(v) * Math.sin(u);
const z = Math.cos(v);

// 归一化到 p 范数单位球面
const r = (Math.abs(x)**p + Math.abs(y)**p + Math.abs(z)**p) ** (1/p);
const px = x / r, py = y / r, pz = z / r;
```
